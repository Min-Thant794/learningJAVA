## 🛠️ Setup & Running

### Prerequisites
- Java JDK 8 or higher — [Download](https://www.oracle.com/java/technologies/downloads/)
- An IDE such as **IntelliJ IDEA** or **Eclipse** (both project configs are included)

### Run in IntelliJ IDEA
1. Open the root folder — IntelliJ will detect the `.idea` project automatically.
2. Navigate to any `.java` file in `JavaCode/src/`.
3. Click the green ▶ **Run** button or press `Shift + F10`.

### Run in Eclipse
1. Go to **File → Open Projects from File System** and select the `JavaCode/` folder.
2. Eclipse will detect the `.project` and `.classpath` files.
3. Right-click any file → **Run As → Java Application**.

### Run from the command line
```bash
cd learningJAVA/JavaCode/src
javac exercises/BmiCalculator.java
java exercises.BmiCalculator
```
